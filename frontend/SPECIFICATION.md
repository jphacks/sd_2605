# システム仕様書（フロントエンド基準）

## 1. 目的
家族・友人が短い音声メッセージをWebから登録し、帰宅を検知した家庭用デバイスがその音声を再生する。Home画面は音声自体を再生せず、登録状態とデバイス状態を表示する。

## 2. システム境界
- Web frontend: ログイン、デバイス選択、録音・試聴・WAV変換・登録、状態・履歴・音量設定表示
- Backend (Rails想定): Web認証、デバイス認可、データ保存、音声配信、イベント管理、デバイス向けAPI
- Hardware (M5Stack): heartbeat、音声取得・ローカルキャッシュ、帰宅検知、再生、イベント送信

WebフロントエンドはM5Stackに直接接続しない。Web向けBearer tokenとデバイス向け認証は分離する。

## 3. 機能要件
| ID | 要件 | 状態 |
|---|---|---|
| FR-01 | メールアドレス・パスワードでアカウント登録・ログインできる | 実装済み（API接続は要検証） |
| FR-02 | 複数デバイスを登録し、ログイン済みデバイスを切り替えられる | 実装済み |
| FR-03 | デバイス表示名を変更し、一覧から外せる | 実装済み（ブラウザ内のみ） |
| FR-04 | オンライン状態・最終通信・音声登録状況を表示できる | 実装済み（API接続は要検証） |
| FR-05 | イベント履歴を表示できる | 実装済み（API接続は要検証） |
| FR-06 | 5秒以内の音声を録音・試聴できる | 実装済み（ブラウザ実機確認が必要） |
| FR-07 | 録音音声をmono PCM16 16 kHz WAVへ変換できる | 実装済み（対象ブラウザで検証必要） |
| FR-08 | WAV音声を登録できる | 実装済み（API接続は要検証） |
| FR-09 | 音量0〜100を取得・更新できる | 実装済み（API接続は要検証） |
| FR-10 | Home画面からサーバー音声を再生できない | UI実装上は再生UIなし |

## 4. 主要データ契約
- 音声: WAV / PCM16 little-endian / mono / 16 kHz / 5秒以内 / 200 KiB以下
- 設定音量: 整数0〜100
- 日時: ISO 8601。UTC保存・送信を推奨
- イベント: `event_id`, `event_type`, `occurred_at`
- 音声メタデータ: `version`, `byte_size`, `content_type`, `path`、任意で`updated_at`, `registered_by`

詳細は `API_CONTRACT.md` を参照。デバイス向けheartbeat・イベント送信はWeb向けAPIとは別に確定する。

## 5. セッション・複数デバイス
- デバイス一覧、表示名、選択中デバイスIDはlocalStorageに保存する。
- ユーザー登録は `POST /api/users`、ログインは `POST /api/user_sessions` を使用する。発行されたJWTは現在選択中のデバイスに紐付けてsessionStorageへ保存し、ブラウザセッション中に限って保持する。
- デバイス管理の再ログインは別の `POST /api/sessions` を使用する。ユーザー認証とデバイス認証の統合、およびユーザーとデバイスのDB上の関連付けは未確定。
- URLのデバイスIDに対応するtokenをリクエストへ付与する。
- 401時は該当デバイスのセッションを消し、イベント通知する。
- フロントエンド上のデバイス切替は認可境界ではない。バックエンドでtokenとdevice_idの一致を必ず検証する。

## 6. 受け入れ条件
### フロントエンド
- `npm run typecheck` が成功する。
- `npm run build` が成功する。
- 未ログイン時は保護画面へアクセスできない。
- デバイスAからBへ切り替えた際、前の画面状態・録音内容が混在しない。
- 録音、試聴、5秒自動停止、WAV変換、サイズ超過表示を対象ブラウザで確認する。
- API失敗時にローディング状態が解除され、利用者にエラーが表示される。

### バックエンド／ハードウェア統合
- デバイス間の認可分離が保証される。
- 音声登録・取得・ローカル保存・帰宅時再生まで一連で動作する。
- 音声取得失敗や音声未登録でも固定挨拶と通常動作を維持する。
- イベント再送が重複登録を生まない。

## 7. 既知の課題・決定事項
- 現状、自動テストはない。
- APIおよび実機と接続した統合テストは未実施。
- 録音時間は画面のタイマーに依存する。ブラウザの停止遅延を含め、実際のWAV時間をサーバー側で検証すること。
- デモ認証情報の表示はlocalhost/127.0.0.1でのみ表示する実装。実運用の認証情報をフロントエンドに埋め込まない。
- `message_count`、イベント種別、デバイス認証、音声配信URL、ログアウト・削除APIは担当者間で確定する。
