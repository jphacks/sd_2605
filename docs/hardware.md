# M5Stack

M5Unifiedを使用するArduinoスケッチです。

- `firmware/m5stack/core/core.ino`: M5GO-CORE1 v2.7（M5Stack Core）のPIR連動音声再生。
- `firmware/m5stack/cores3/cores3.ino`: CoreS3専用の内蔵カメラ動体・左右方向検知・確認音・タッチUI（Web・外付けセンサー不要、LTR-553不使用）。[操作と検証手順](../firmware/m5stack/cores3/README.md)。

## Coreの接続と準備

電源を切ってUnit PIRをGroveケーブルでPORT Bへ接続します。PIR出力はGPIO36です。GPIO36には内部プルアップを設定しません。スピーカーは内蔵のものを使用します。

microSDカードをFAT32でフォーマットし、ルートへ`welcome.wav`を配置してください。対応形式は **WAV / PCM / モノラル / 16bit / 16kHz** です。MP3や浮動小数点WAVには対応しません。例えば「おかえりなさい」の録音をAudacityでこの形式に書き出すか、インストール済みのffmpegがあれば以下で変換できます。

```powershell
ffmpeg -i input.m4a -ac 1 -ar 16000 -c:a pcm_s16le welcome.wav
```

音声素材は別途用意してください。SD未挿入・ファイル欠落・不正形式ではシリアルに`SD ERROR`を出力し、代わりにチャイムを再生します。読み込み途中のエラーでは残りのバッファを再生してから短い代替音を鳴らします。カードを挿し直した場合はB短押しで再試行でき、認識できなければ本体を再起動してください。使用中のカード抜去は避けてください。

必要なライブラリはM5Unifiedと依存するM5GFXです。この環境ではM5Unified 0.2.26 / M5GFX 0.2.33を使用します。SD/SPIはESP32ボードパッケージ付属です。

## コンパイル・書き込み

リポジトリのルートで実行します。

```powershell
arduino-cli compile --fqbn m5stack:esp32:m5stack_core --output-dir .\build\core .\firmware\m5stack\core
arduino-cli upload -p COM5 --fqbn m5stack:esp32:m5stack_core --input-dir .\build\core .\firmware\m5stack\core
```

従来のコンパイルと書き込みを一括実行するコマンドも利用できます。

```powershell
arduino-cli compile -u -p COM5 --fqbn m5stack:esp32:m5stack_core .\firmware\m5stack\core
```

シリアルログは115200 baudです。モニターを閉じてから書き込んでください。

```powershell
arduino-cli monitor -p COM5 --config baudrate=115200
```

## 動作と操作

起動後3秒はボタン入力を受け付けません。

- A（左）を押す: 内蔵マイクで3秒間録音します。録音中は歌う表情になります。新しい録音で前の録音を置き換えます。
- B（中央）を押す: 直近の録音を再生します。録音前は再生せずシリアルに案内を出します。長押しでも操作は1回です。
- 録音・再生中、PIR検知後の再生待ち中はA/Bを受け付けません。録音中もPIR再生を開始しません。
- 録音は16kHz・16bit・モノラルで本体RAMに3秒分保存します。SDカード不要ですが再起動で消えます。PIR再生は従来どおりSDの`/welcome.wav`または代替チャイムです。
- C短押し（右）: ピンクの女の子 → 黄色の友達 → 青の眼鏡の男の子を切り替えます。選択は再起動後も復元します。C長押しは操作なしです。

起動時には短い確認音が鳴ります。PIRのLOW→HIGHで検知回数を増やし、150ms後に音声を再生します。手動再生では検知回数を増やしません。再生後10秒間はPIR検知を受け付けず、次のLOW→HIGHを待ちます。起動時からHIGHの場合も一度LOWになる必要があります。手動再生後も10秒の待機を最初から開始します。

画面全体には元の`faces.ino`（現在の`faces.h`）の顔だけを描画します。温湿度・検知回数・挨拶・状態・エラー・操作ガイドなどの文字や待機バーは表示しません。音声再生中・検知中・待機中は表情で状態を示します。エラーは115200 baudのシリアルログで確認してください。

### はじめてのテスト

1. 起動後3秒待ち、Aを押して話しかけます。シリアルの`recording start`から約3秒後に`recording ready`になることを確認します。
2. Bで直近の録音が聞こえること、繰り返し再生できることを確認します。
3. Aで別の言葉を録音し、Bで新しい録音が再生されることを確認します。録音・再生中に連打しても処理が重複しないことを確認します。
4. 再起動後、録音前のBでは音が出ないことを確認します。
5. Cの顔切り替え、PIRのSD音声またはチャイム再生を確認します。

`COOLDOWN_MS`、`DETECT_DISPLAY_MS`、`VOLUME`、`WELCOME_PATH`はスケッチ先頭で変更できます。WAVは1024バイト×2の固定バッファで逐次読み込み、再生中のバッファを上書きしません。Wi-Fiやアップロード機能は含みません。

## 実機確認項目

1. 起動音が1回鳴り、画面全体に文字なしの顔が表示されること。
2. PIRの前を通過すると検知回数が増え、WAVまたは代替チャイムが1回鳴ること。
3. HIGH保持中に再生を繰り返さず、再生終了後10秒間は検知を受け付けないこと。
4. LOWへ戻った後、クールダウン終了後の次の立ち上がりで再生できること。
5. B短押しで再生でき、連打しても音声が重複しないこと。
6. B長押しで消音・解除が動作し、離したときに再生しないこと。
7. SDなし、ファイルなし、不正WAVでシリアルへのエラー出力と代替音が動作し、画面は顔だけのままであること。
8. 正常WAVで音声が途切れず、再生開始・終了とPIR変化が115200 baudで記録されること。

コンパイル・書き込みの成否と、上記の実機検証結果は別々に確認してください。
